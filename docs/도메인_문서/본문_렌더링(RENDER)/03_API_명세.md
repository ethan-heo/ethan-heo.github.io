# 본문 렌더링(RENDER) — API 명세

## 엔드포인트 목록

해당 없음. 이 도메인은 HTTP 엔드포인트를 만들지 않고 빌드 시점의 변환만 맡는다. 아래는 이 도메인이 노출하는 두 가지 계약, 곧 마크다운 표기법과 명령줄 인터페이스다.

| 계약 | 형태 | 설명 | 인증 |
| --- | --- | --- | --- |
| 폭 표기 | 마크다운 이미지 title | 본문 이미지의 표시 폭을 지정한다 | 불필요 |
| `npm run images` | 명령줄 | 글 폴더의 이미지를 WebP로 줄인다 | 불필요 |

## 폭 표기

이미지 링크의 title 자리에 `w=<폭>`을 적으면 그 폭으로 표시한다.

### 요청

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| title | `w=<값>` | `string` | 아니오 | `400` 또는 `400px` 형태의 양의 정수. 앞뒤 공백은 허용한다 |

```markdown
![폴더 구조](./folder-structure.webp "w=400")
```

### 응답

```html
<img src="/_astro/folder-structure.hash.webp" alt="폴더 구조"
     style="max-width: min(400px, 100%); display: block; margin-inline: auto;">
```

`title` 속성은 결과에 남지 않는다. `setProperty`로는 속성을 지울 수 없어 `title`을 뺀 노드로 갈아 끼우기 때문이다.

### 에러 코드

| 상태 | 코드 | 발생 조건 |
| --- | --- | --- |
| 경고 | `[image-width] 폭으로 읽을 수 없는 값이라 무시한다: "<값>"` | title이 `w=`로 시작하지만 뒤가 양의 정수가 아니다 |
| 무시 | 없음 | title이 `w=`로 시작하지 않는다. 정상 동작이므로 알리지 않는다 |

## `npm run images`

글 폴더의 이미지를 최대 폭 1360px WebP로 바꾸고 마크다운 참조까지 고친다. 커밋 전에 실행한다.

### 요청

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| argv[2] | 대상 디렉터리 | `string` | 아니오 | 기본값 `src/content/posts`. 글 폴더 하나만 지정할 수 있다 |

```bash
npm run images
npm run images -- "src/content/posts/hello-blog"
```

### 응답

```
변환: src/content/posts/hello-blog/folder-structure.png (2048px) -> src/content/posts/hello-blog/folder-structure.webp
  참조 갱신: src/content/posts/hello-blog/index.md
경고: 건너뜀 src/content/posts/hello-blog/demo.gif — 움직이는 이미지라 변환하면 움직임이 사라진다
```

### 에러 코드

| 종료 코드 | 메시지 | 발생 조건 |
| --- | --- | --- |
| 1 | `디렉터리가 아닙니다: <경로>` | 인자로 준 경로가 없거나 디렉터리가 아니다 |
| 1 | `오류: <대상>가 이미 있어 덮어쓰지 않는다...` | 변환 결과와 같은 이름의 파일이 이미 있다 |
| 0 | `경고: 건너뜀 ... — 움직이는 이미지라...` | 애니메이션 GIF다 |
| 0 | `경고: 건너뜀 ... — 이미 WebP이고 폭도 기준 이하다` | 변환할 필요가 없다 |
| 0 | `경고: <파일>을 본문에서 참조하지 않는다` | 변환은 했지만 `index.md`에 참조가 없다 |
| 0 | `바꿀 이미지가 없습니다.` | 대상 폴더에 이미지 파일이 하나도 없다 |

오류가 하나라도 있으면 나머지 이미지를 모두 처리한 뒤 종료 코드 1로 끝난다. 공통 에러 규약은 [`공통_에러_코드.md`](../../공통_인프라_및_컨벤션/공통_에러_코드.md)를 참조한다.
