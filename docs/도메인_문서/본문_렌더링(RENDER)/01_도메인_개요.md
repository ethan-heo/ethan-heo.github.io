# 본문 렌더링(RENDER) — 도메인 개요

계획서 출처: `docs/plans/2026-08-29-prose-image-width/prose/`, `docs/plans/2026-08-29-post-image-assets/image/`

## 도메인 정의

본문 렌더링 도메인은 마크다운 본문을 읽을 수 있는 HTML로 바꾸는 변환 규칙을 맡는다. 소제목 앵커 부여, 이미지 표시 폭 지정, 코드 하이라이팅 설정이 여기에 속하고, 저장소에 커밋하기 전 이미지 원본을 줄이는 변환 명령도 같은 도메인이 관리한다.

글의 자료 구조와 선별은 [`콘텐츠(CONTENT)`](../콘텐츠(CONTENT)/01_도메인_개요.md)가, 변환된 본문에 입히는 시각 규칙 중 색과 서체 토큰은 [`디자인_시스템(DESIGN)`](../디자인_시스템(DESIGN)/01_도메인_개요.md)이 맡는다.

### 책임 범위

| 구분 | 내용 |
| --- | --- |
| 담당한다 | `h2`·`h3` 앵커와 `id` 부여, 이미지 title의 폭 표기 해석, Shiki 두 테마 출력 설정, `.prose` 본문 조판 규칙, 이미지 최적화 스크립트와 마크다운 참조 갱신 |
| 담당하지 않는다 | 프론트매터 스키마와 글 선별(CONTENT), 색·서체 토큰 정의(DESIGN), 목차 마크업 구성(POST) |

## 유비쿼터스 용어 사전

| 용어 | 영문 표기 | 정의 |
| --- | --- | --- |
| 본문 | `.prose` | 마크다운에서 나온 HTML을 감싸는 영역. 전역 스타일이 이 클래스 아래에서만 적용된다 |
| 하스트 플러그인 | `hastPlugins` | satteri 프로세서가 HTML 트리를 순회하며 노드를 고치도록 등록하는 함수 |
| 소제목 앵커 | `heading-anchors` | `h2`·`h3`에 `id`와 문단 링크를 붙이는 플러그인 |
| 폭 표기 | `w=400` | 이미지 링크 title 자리에 적어 표시 폭을 지정하는 문법 |
| 이미지 폭 플러그인 | `image-width` | 폭 표기를 읽어 인라인 스타일로 바꾸는 플러그인 |
| 이미지 최적화 | `npm run images` | 글 폴더의 이미지를 최대 폭 1360px WebP로 바꾸는 명령 |
| 글 폴더 | — | `<이름>/index.md`와 그 글이 쓰는 이미지를 함께 담는 디렉터리 |

## 핵심 비즈니스 규칙

1. `h2`와 `h3`에는 본문 텍스트에서 만든 슬러그를 `id`로 부여한다. 이미 `id`가 있으면 그 값을 그대로 쓴다.
2. 앵커로 이동한 제목이 키보드 포커스를 받을 수 있도록 `tabindex="-1"`을 함께 넣는다.
3. 앵커 글자는 마크업에 넣지 않고 CSS로 그린다. 마크업에 넣으면 제목 텍스트에 딸려 와 목차와 접근성 이름을 오염시킨다.
4. 이미지 폭은 링크 title이 `w=`로 시작할 때만 해석한다. `400`이나 `400px` 형태의 양의 정수만 받는다.
5. 폭을 읽어 낸 이미지는 `max-width: min(<폭>px, 100%)`와 `display: block`, `margin-inline: auto`를 인라인 스타일로 받고 `title` 속성을 잃는다. 본문 폭을 넘지 않도록 `min()`으로 묶는다.
6. 폭으로 읽을 수 없는 값이면 경고를 남기고 이미지를 그대로 둔다. 표기가 잘못됐다고 이미지를 지우지는 않는다.
7. 이 처리는 이미지 파일이 만들어진 뒤에 일어나므로 파일 크기는 달라지지 않는다. 줄어드는 것은 표시 폭뿐이다.
8. 코드 블록은 라이트와 다크 두 테마의 색을 함께 내보내고, 전환은 `global.css`가 맡는다.
9. 이미지 최적화는 최대 폭 1360px WebP로 바꾸고 원본을 지운다. 1360px은 본문 폭 680px의 두 배로, 고해상도 화면에서도 선이 흐리지 않은 값이다.
10. 변환한 이미지의 참조는 같은 폴더의 `index.md`에서만 고친다. 다른 글의 본문은 건드리지 않는다.

### 예외 케이스

| 상황 | 처리 |
| --- | --- |
| 앞선 `h2` 없이 `h3`가 먼저 나온다 | 앵커는 정상적으로 붙는다. 목차 계층 처리는 POST 도메인이 맡는다 |
| title이 `w=`로 시작하지 않는다 | 아무것도 하지 않고 title을 그대로 남긴다 |
| `w=abc`나 `w=0`처럼 읽을 수 없는 값이다 | `[image-width] 폭으로 읽을 수 없는 값이라 무시한다: "..."`를 경고로 남기고 이미지를 그대로 둔다 |
| 지정한 폭이 본문 폭보다 넓다 | `min(<폭>px, 100%)`가 본문 폭에서 멈춘다 |
| 움직이는 GIF를 최적화한다 | 변환하면 움직임이 사라지므로 건너뛰고 경고를 남긴다 |
| 이미 WebP이고 폭도 1360px 이하다 | 건너뛴다 |
| 같은 이름의 `.webp`가 이미 있다 | 덮어쓰지 않고 오류로 끝낸다. 한쪽을 지우거나 이름을 바꾼 뒤 다시 실행한다 |
| 원본이 1360px보다 좁다 | 확대하지 않고 형식만 바꾼다 |
| 이미지를 본문에서 참조하지 않는다 | 변환은 하되 참조가 없다고 경고한다 |
| 참조가 `http`나 `/`로 시작한다 | 상대 경로 패턴에 걸리지 않아 갱신 대상에서 빠진다 |
