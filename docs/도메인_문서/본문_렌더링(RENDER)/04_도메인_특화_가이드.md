# 본문 렌더링(RENDER) — 도메인 특화 가이드

## 외부 의존성

| 대상 | 종류 | 용도 |
| --- | --- | --- |
| `@astrojs/markdown-satteri` | 라이브러리 | 마크다운 프로세서. `hastPlugins`로 HTML 트리를 고칠 자리를 준다 |
| `github-slugger` | 라이브러리 | 소제목 텍스트에서 겹치지 않는 `id`를 만든다 |
| `sharp` | 라이브러리 | 이미지 크기 조정과 WebP 변환. `devDependencies`에 둔다 |
| Shiki | Astro 내장 | 코드 하이라이팅. `github-light`와 `github-dark`를 함께 내보낸다 |
| `node:fs/promises` | 런타임 모듈 | 최적화 스크립트의 파일 읽기·쓰기·이름 바꾸기 |

### 설정

| 항목 | 값의 출처 | 비고 |
| --- | --- | --- |
| `markdown.shikiConfig.themes` | `astro.config.mjs` | `{ light: 'github-light', dark: 'github-dark' }` |
| `markdown.processor` | `astro.config.mjs` | `satteri({ hastPlugins: [headingAnchors(), imageWidth()] })` |
| `MAX_WIDTH` | `scripts/optimize-images.mjs` 상수 | 1360. 본문 폭 680px의 두 배 |
| `IMAGE_EXTENSIONS` | 같은 파일의 상수 | `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`, `.gif` |
| WebP 품질 | 같은 파일의 `webp({ quality: 82 })` | 82 |
| `POSTS_ROOT` | 같은 파일의 상수 | `src/content/posts` |

## 핵심 테스트 시나리오

| ID | 상황 | 기대 동작 |
| --- | --- | --- |
| T1 | 소제목이 있는 글을 렌더링한다 | `h2`·`h3`에 슬러그 `id`와 `tabindex="-1"`, 문단 링크가 붙고 목차 텍스트에는 `#`가 섞이지 않는다 |
| T2 | `w=400`을 적은 이미지를 렌더링한다 | `max-width: min(400px, 100%)`와 가운데 정렬이 붙고 `title`이 사라진다 |
| T3 | `w=400px`, ` w = 400 ` 형태를 적는다 | 400px로 해석한다 |
| T4 | `w=abc`, `w=0`, `w=-5`를 적는다 | 경고를 남기고 이미지를 그대로 둔다 |
| T5 | title에 `w=`가 아닌 문구를 적는다 | 아무것도 하지 않고 title을 남긴다 |
| T6 | `w=5000`을 적는다 | 본문 폭에서 멈추고 가로 스크롤이 생기지 않는다 |
| T7 | 1360px보다 넓은 PNG에 `npm run images`를 돌린다 | 1360px WebP가 되고 원본이 사라진다 |
| T8 | 변환 후 마크다운을 확인한다 | 상대 경로 참조의 확장자가 `.webp`로 바뀐다 |
| T9 | 애니메이션 GIF, 기준 이하 WebP, 이름이 겹치는 파일, 좁은 원본, 참조 없는 파일, 디렉터리가 아닌 인자를 각각 준다 | 예외 표의 여섯 조건대로 각각 건너뛰거나 오류로 끝난다 |
| T10 | 코드 블록이 있는 글을 두 테마에서 본다 | 두 테마의 색이 함께 나오고 전환 시 글자 색이 따라 바뀐다 |

### 실행 방법

```bash
npm run build
npm run images -- "src/content/posts/<글 폴더>"
```

## 트러블슈팅

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 이미지가 지정한 폭으로 줄지 않는다 | title 표기가 `w=`로 시작하지 않거나 값이 정수가 아니다 | 빌드 로그의 `[image-width]` 경고를 확인하고 `w=400` 형태로 고친다 |
| 폭을 줄였는데 파일 용량이 그대로다 | 폭 표기는 표시 폭만 바꾼다 | 파일 자체를 줄이려면 `npm run images`를 돌린다 |
| 이미지가 본문 폭을 넘어 가로 스크롤이 생긴다 | 인라인 스타일 없이 원본 크기로 나온다 | `.prose img`의 `max-width: 100%`가 적용되는지, 인라인 스타일이 이를 덮지 않는지 확인한다 |
| 목차 항목에 `#`가 섞여 나온다 | 앵커 글자를 마크업에 넣었다 | 앵커는 CSS로 그린다. `heading-anchors`가 빈 `a`만 넣는지 확인한다 |
| 앵커로 이동해도 키보드 포커스가 제목에 가지 않는다 | `tabIndex`가 빠졌다 | `heading-anchors`의 `setProperty(node, 'tabIndex', -1)`을 확인한다 |
| `npm run images`가 오류로 끝난다 | 같은 이름의 `.webp`가 이미 있다 | 한쪽을 지우거나 이름을 바꾼 뒤 다시 실행한다 |
| 변환 후 본문의 이미지가 깨진다 | 참조가 `/`나 `http`로 시작해 갱신 대상에서 빠졌다 | 상대 경로 `./<이름>` 형태로 고친다 |
| 다크 테마에서 코드 글자가 검게 보인다 | `--shiki-dark` 덮어쓰기 규칙이 적용되지 않았다 | `Prose.astro`의 `[data-theme='dark'] .prose .astro-code` 규칙을 확인한다 |
