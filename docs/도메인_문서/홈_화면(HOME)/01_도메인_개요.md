# 홈 화면(HOME) — 도메인 개요

계획서 출처: `docs/plans/2026-08-28-home-screen/home/`, `docs/plans/2026-08-28-home-screen-refinement/home/`, `docs/plans/2026-08-28-home-recent-posts/home/`, `docs/plans/2026-08-29-home-key-point/home/`

## 도메인 정의

홈 화면 도메인은 `/` 한 화면을 맡는다. 블로그의 성격을 알리는 머리말, 앞세울 글을 격자로 보이는 지식 맵, 최신 글 다섯 편의 한 줄 목록이 이 화면의 구성 요소다.

어느 글을 앞세울지 고르는 규칙은 [`콘텐츠(CONTENT)`](../콘텐츠(CONTENT)/01_도메인_개요.md)에 있고, 이 도메인은 넘겨받은 글을 배치하는 일만 한다. 색과 서체, 헤더와 푸터는 [`디자인_시스템(DESIGN)`](../디자인_시스템(DESIGN)/01_도메인_개요.md)이 맡는다.

### 책임 범위

| 구분 | 내용 |
| --- | --- |
| 담당한다 | `/` 페이지 조합, 지식 맵 격자의 배치와 테두리 규칙, 노드 표현, 최신 글 한 줄 목록, 홈의 머리말과 섹션 문구 |
| 담당하지 않는다 | 지식 맵에 올릴 글의 선별과 읽기 시간 산출(CONTENT), 헤더·푸터·토큰(DESIGN), 모든 글 화면(POST) |

## 유비쿼터스 용어 사전

| 용어 | 영문 표기 | 정의 |
| --- | --- | --- |
| 지식 맵 | `KnowledgeMap` | 앞세울 글을 다섯 칸 격자로 보이는 영역. 섹션 제목은 「최근 생각」이다 |
| 노드 | `MapNode` | 격자의 칸 하나. 순번, 제목, 분류와 읽기 시간을 담는다 |
| 중심 글 | featured | 격자의 첫 칸. 다른 칸보다 크고 보조 배경색을 쓴다 |
| 빈 칸 | blank | 글이 모자랄 때 격자 모양을 지키려고 채우는 칸. 링크가 없고 보조 기술에서 감춘다 |
| 테두리 방향 규칙 | `MAP_EDGE_CLASSES` | 칸마다 어느 방향의 선을 그릴지 배치 순서대로 적어 둔 값 |
| 최신 글 목록 | `RecentPostList` | 제목과 날짜만 한 줄에 담는 목록 |
| 화면 머리말 | `PageIntro` | 눈썹 문구, 제목, 설명 세 줄 |

## 핵심 비즈니스 규칙

1. 홈은 머리말, 지식 맵, 최신 글 세 영역을 조합하는 호출만 담는다. 마크업과 `<style>` 블록을 페이지 파일에 두지 않는다.
2. 지식 맵과 최신 글은 각각 글이 한 편 이상일 때만 그린다.
3. 격자는 언제나 다섯 칸을 채운다(`MAP_CELL_COUNT`). 글이 모자라면 빈 칸으로 메운다.
4. 한 선은 한 칸만 그린다. 칸은 자기 왼쪽과 위쪽만 그리고 첫 열과 첫 행에서는 해당 방향을 그리지 않는다. 선이 겹쳐 어긋나 보이는 것을 막기 위한 규칙이다.
5. 격자 위아래의 바깥선은 컨테이너가 맡고 좌우 바깥선은 그리지 않는다.
6. 좁은 화면은 두 열이고 중심 글이 첫 행 전체를 차지한다. 701px 이상에서는 세 열이 되고 중심 글이 첫 열에서 두 행을 차지한다.
7. 노드의 순번은 글에 적은 값이 아니라 배치 순서다. 두 자리로 채워 `01` 형태로 적는다.
8. 중심 글의 순번 자리에는 `01 / 중심 글`이라고 적는다.
9. 노드와 목록 항목은 전체가 링크지만, 링크의 접근 가능한 이름은 제목만 가리킨다. 요약과 날짜가 이름에 섞이지 않게 `aria-labelledby`로 묶는다.
10. 섹션 제목은 「최근 생각」과 「최신 글」이다. 최근 생각에는 글 수를, 최신 글에는 `/posts`로 가는 「전체 보기」 링크를 붙인다.
11. 최신 글 목록의 긴 제목은 말줄임으로 자르고 날짜는 줄바꿈하지 않는다.
12. 헤더 아래 가로선과 최신 글 사이 구분선은 두지 않는다. 목록의 위아래 바깥선만 남긴다.

### 예외 케이스

| 상황 | 처리 |
| --- | --- |
| 지식 맵에 올릴 글이 없다 | 섹션 전체를 그리지 않는다 |
| 글이 1~4편이다 | 격자의 자식 요소는 다섯 개를 유지하고 남는 자리는 빈 칸이 된다. 빈 칸에는 링크가 없고 `aria-hidden`으로 감춘다 |
| 빈 칸만 남은 행이 생긴다 | 글이 든 칸과 같은 최소 높이를 줘 납작해지지 않게 한다 |
| `category`가 없는 글이다 | 읽기 시간만 남기고 구분용 가운뎃점을 넣지 않는다 |
| 발행한 글이 하나도 없다 | 최신 글 섹션도 그리지 않는다. 머리말만 남는다 |
| 제목이 목록 폭을 넘는다 | 말줄임으로 자른다 |
