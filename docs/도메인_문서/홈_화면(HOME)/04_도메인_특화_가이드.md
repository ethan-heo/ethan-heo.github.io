# 홈 화면(HOME) — 도메인 특화 가이드

## 외부 의존성

해당 없음. 이 도메인만 독점적으로 쓰는 외부 패키지나 서비스가 없다. 화면은 다음 내부 모듈에만 기댄다.

| 대상 | 종류 | 용도 |
| --- | --- | --- |
| `src/lib/posts.ts` | 내부 모듈 | `getMapPosts`, `getRecentPosts`, `getReadingMinutes`, `toPostUrl` |
| `src/lib/mapGrid.ts` | 내부 모듈 | `MAP_EDGE_CLASSES`, `MAP_CELL_COUNT` |
| `Intl.DateTimeFormat` | 브라우저·런타임 API | 날짜를 `2026.08.27` 형태로 맞춘다 |

프로젝트 전반의 의존성은 [`글로벌_아키텍처_가이드.md`](../../글로벌_아키텍처_가이드.md)에 둔다.

### 설정

| 항목 | 값의 출처 | 비고 |
| --- | --- | --- |
| `MAP_CELL_COUNT` | `src/lib/mapGrid.ts` | `MAP_EDGE_CLASSES.length`에서 파생한다. 직접 적지 않는다 |
| 날짜 서식 | `RecentPostList.astro` | `ko-KR`, `2-digit`. 점 구분자로 바꾼다 |
| 재배치 경계 | `--breakpoint-wide` | 701px. DESIGN 도메인이 정의한다 |

## 핵심 테스트 시나리오

| ID | 상황 | 기대 동작 |
| --- | --- | --- |
| T1 | 다섯 칸의 테두리를 두 화면 폭에서 확인한다 | 방향 규칙 표와 일치하고 선이 겹치지 않는다 |
| T2 | 격자 좌우 바깥을 본다 | 세로선이 없고 위아래 바깥선만 있다 |
| T3 | 글을 1~4편 둔다 | 격자의 자식이 항상 다섯이고 빈 칸에는 링크가 없으며 보조 기술에서 감춰진다 |
| T4 | 글을 하나도 두지 않는다 | 지식 맵과 최신 글 섹션이 그려지지 않는다 |
| T5 | `category`가 없는 글을 노드에 올린다 | 구분용 가운뎃점이 남지 않고 링크 이름이 제목뿐이다 |
| T6 | 노드의 세 요소를 본다 | 순번·제목·메타의 크기 위계가 구분되고 지어낸 문구가 없다 |
| T7 | 글을 여섯 편 이상 둔다 | 최신 글이 다섯 편만 나오고 최신순이다 |
| T8 | 긴 제목을 가진 글을 목록에 올린다 | 말줄임으로 잘리고 날짜가 줄바꿈하지 않는다 |
| T9 | 섹션 머리를 확인한다 | 「최신 글」에는 보조 텍스트가 없고 「전체 보기」가 `/posts`를 가리킨다 |
| T10 | 헤더와 목록의 선을 본다 | 헤더 아래 가로선이 없고 목록 항목 사이에 선이 없으며 위아래 바깥선만 하나씩 있다 |
| T11 | 머리말의 문구를 확인한다 | 배너 세 문구가 정한 문장과 글자 단위로 같고 `<title>`·`description`이 같은 문구를 담는다 |
| T12 | 페이지 파일을 연다 | 마크업과 `<style>` 블록이 남아 있지 않다 |
| T13 | `keyPoint`를 표시한 글 수를 바꾼다 | 표시한 글 수와 격자에 나타난 글 수가 일치한다 |

### 실행 방법

```bash
npm run dev
```

배치와 선 검증은 개발 서버 화면과 브라우저 개발자 도구의 계산값으로 확인한다.

## 트러블슈팅

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 격자의 선이 어긋나 두껍게 보인다 | 두 칸이 같은 선을 각각 그렸다 | `MAP_EDGE_CLASSES`의 방향과 배치 순서가 맞는지 확인한다. 칸은 왼쪽과 위쪽만 그린다 |
| 격자 좌우에 세로선이 생긴다 | 칸에 `border-r`이나 컨테이너에 `border-x`를 넣었다 | 좌우 바깥선은 그리지 않는 규칙이다 |
| 빈 칸만 남은 행이 납작하다 | 빈 칸에 최소 높이를 주지 않았다 | 글이 든 칸과 같은 `min-h`를 준다 |
| 지식 맵이 통째로 보이지 않는다 | `keyPoint`를 표시한 글이 없고 발행한 글도 없다 | 글을 발행하거나 `keyPoint`를 표시한다 |
| 넣고 싶은 글이 격자에 없다 | 다른 글이 이미 다섯 칸을 채웠다 | [`콘텐츠(CONTENT)`](../콘텐츠(CONTENT)/01_도메인_개요.md)의 선별 규칙을 따라 `keyPoint`를 조정한다 |
| 노드 메타 줄이 `· 3분 읽기`로 시작한다 | 빈 `category`를 걸러 내지 않았다 | `filter(Boolean)`으로 빈 값을 떨어뜨린 뒤 잇는다 |
| 링크를 읽을 때 요약과 날짜가 함께 읽힌다 | `aria-labelledby`가 빠졌다 | 제목 요소의 `id`를 링크가 가리키게 한다 |
| 넓은 화면에서 중심 글이 커지지 않는다 | `wide` 경계가 적용되지 않았다 | `--breakpoint-wide`가 701px로 정의돼 있는지 확인한다 |
