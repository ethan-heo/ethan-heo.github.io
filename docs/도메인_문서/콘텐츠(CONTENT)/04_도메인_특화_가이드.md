# 콘텐츠(CONTENT) — 도메인 특화 가이드

## 외부 의존성

| 대상 | 종류 | 용도 |
| --- | --- | --- |
| `astro:content` | 프레임워크 모듈 | 컬렉션 정의, `getCollection`, `getEntry`, `reference` |
| `astro/loaders`의 `glob` | 프레임워크 모듈 | `src/content/posts` 아래 마크다운을 읽어 들이고 `.obsidian`을 제외한다 |
| `zod`(`astro:content`가 재노출) | 라이브러리 | 프론트매터 스키마 검증 |

프로젝트 전반이 쓰는 의존성은 [`글로벌_아키텍처_가이드.md`](../../글로벌_아키텍처_가이드.md)에 둔다.

### 설정

| 항목 | 값의 출처 | 비고 |
| --- | --- | --- |
| `import.meta.env.PROD` | Astro 빌드 환경 | 초안 노출 판정에 쓴다. 개발 서버에서는 거짓 |
| `RECENT_POST_LIMIT` | `src/lib/posts.ts` 상수 | 5. 홈 최신 글 개수 |
| `MAP_NODE_LIMIT` | `src/lib/posts.ts` 상수 | 5. 시안의 격자가 다섯 칸이다 |
| `CHARS_PER_MINUTE` | `src/lib/posts.ts` 상수 | 500. 기술 글을 천천히 읽는 상황에 맞춘 값 |
| 콘텐츠 루트 | `src/content.config.ts`의 `base` | `./src/content/posts` |

환경 변수 파일은 쓰지 않는다.

## 핵심 테스트 시나리오

| ID | 상황 | 기대 동작 |
| --- | --- | --- |
| T1 | `title`을 뺀 글을 두고 빌드한다 | 빌드가 멈추고 파일 경로와 필드 이름을 알린다 |
| T2 | `tags`와 `draft`를 적지 않은 글을 둔다 | 기본값으로 통과한다 |
| T3 | 개발 서버와 운영 빌드에서 초안 글을 각각 확인한다 | 개발에서는 보이고 운영 산출물에는 경로조차 없다 |
| T4 | 발행일이 다른 글 두 편을 둔다 | 목록에서 최신 글이 먼저 나온다 |
| T5 | 글을 여섯 편 이상 둔다 | `getRecentPosts`가 다섯 편만 돌려준다 |
| T6 | `keyPoint`를 표시한 글을 0편, 3편, 7편으로 바꾼다 | 각각 최신 5편, 그 3편, 발행일이 늦은 5편이 나온다 |
| T7 | 본문이 빈 글과 500자 단위로 늘린 글을 둔다 | 각각 1분과 500자마다 1분씩 늘어난 값이 나온다 |
| T8 | `related`를 비우고, 초안을 가리키고, 없는 글을 가리킨다 | 앞의 둘은 `undefined`, 마지막은 예외 |
| T9 | 하위 폴더에 둔 글의 주소를 확인한다 | `toSlugPath`가 `post.id`와 같은 값을 돌려주고 연월이 두 번 나오지 않는다 |
| T10 | 검색 항목의 `text`를 확인한다 | 제목·요약·태그만 들어가고 다른 필드는 들어가지 않는다 |

### 실행 방법

```bash
npm run build
```

자동화된 단위 테스트 도구는 아직 도입하지 않았다. 위 시나리오는 빌드 결과와 개발 서버 화면으로 확인한다.

## 트러블슈팅

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 빌드가 프론트매터 오류로 멈춘다 | 필수 필드 누락이나 타입 불일치 | 메시지가 알려 준 파일의 `title`, `date`, `summary`를 확인한다 |
| `related`가 가리키는 글을 찾을 수 없다는 예외가 난다 | 대상 글을 지웠거나 폴더 이름을 바꿔 `id`가 달라졌다 | `related` 값을 새 `id`로 고치거나 필드를 지운다 |
| 글을 새로 썼는데 목록에 없다 | `draft: true`인 채로 운영 빌드를 돌렸다 | `draft`를 `false`로 바꾸거나 개발 서버에서 확인한다 |
| 지식 맵에 넣고 싶은 글이 나오지 않는다 | `keyPoint`를 표시한 다른 글이 이미 5편을 채웠다 | 앞세울 글을 다시 고르거나 다른 글의 `keyPoint`를 내린다 |
| 글 주소에 연월이 두 번 나온다 | 폴더 경로와 별도로 발행일을 접두사로 붙이던 옛 규칙 | `toSlugPath`는 `post.id`만 돌려준다. 폴더 구조로 주소를 정한다 |
| 옵시디언 설정 파일이 글로 잡힌다 | 로더 `pattern`의 제외 규칙이 빠졌다 | `src/content.config.ts`의 `'!**/.obsidian/**'`을 확인한다 |
