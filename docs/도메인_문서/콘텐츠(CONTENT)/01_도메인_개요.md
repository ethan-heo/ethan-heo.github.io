# 콘텐츠(CONTENT) — 도메인 개요

계획서 출처: `docs/plans/2026-08-27-blog-environment/blog/`, `docs/plans/2026-08-28-home-screen/base/data.md`, `docs/plans/2026-08-29-post-route-path/route/`, `docs/plans/2026-08-29-home-key-point/home/keypoint.md`

## 도메인 정의

콘텐츠 도메인은 마크다운 파일을 글이라는 자료로 바꾸고, 그 글을 화면이 요구하는 형태로 골라 넘긴다. 프론트매터 스키마 정의, 초안 판별, 발행일 정렬, 지식 맵 선별, 읽기 시간 산출, 글 주소 생성이 모두 이 도메인의 몫이다.

화면이 글을 어떻게 배치하고 어떤 문구로 보이는지는 담당하지 않는다. 마크다운 본문을 HTML로 바꾸는 변환 규칙도 [`본문_렌더링(RENDER)`](../본문_렌더링(RENDER)/01_도메인_개요.md)이 맡는다.

### 책임 범위

| 구분 | 내용 |
| --- | --- |
| 담당한다 | 콘텐츠 컬렉션 스키마 정의, 초안 노출 판정, 발행일 정렬, 최신 글·지식 맵 글 선별, 읽기 시간 산출, `related` 참조 해석, 글 주소 생성, 검색용 색인 문자열 생성 |
| 담당하지 않는다 | 마크다운 → HTML 변환과 이미지 폭 처리(RENDER), 색·서체 토큰(DESIGN), 화면 배치와 문구(HOME, POST) |

## 유비쿼터스 용어 사전

| 용어 | 영문 표기 | 정의 |
| --- | --- | --- |
| 글 | `Post` | `src/content/posts` 아래 `index.md` 한 편과 그 프론트매터를 합친 자료. `CollectionEntry<'posts'>`의 별칭이다 |
| 초안 | `draft` | 아직 공개하지 않은 글. 개발 서버에서만 보인다 |
| 노출 대상 글 | `getVisiblePosts` | 초안 규칙을 통과해 화면에 실을 수 있는 글의 집합 |
| 중심 글 | `keyPoint` | 작성자가 앞세우겠다고 표시한 글. 홈 지식 맵의 선별 기준이다 |
| 분류 | `category` | 지식 맵 노드와 글 머리말에 붙는 영역 이름. 태그와 별개다 |
| 이어 볼 글 | `related` | 다 읽은 뒤 이어서 볼 글을 가리키는 참조 |
| 읽기 시간 | `getReadingMinutes` | 본문 글자 수로 산출한 분 단위 예상 시간 |
| 주소 조각 | `toSlugPath` | 글 주소에서 `/posts/` 뒤에 붙는 경로. `post.id`와 같다 |
| 검색 항목 | `SearchEntry` | 검색과 정렬에 필요한 값만 남긴 글 하나의 표현 |

## 핵심 비즈니스 규칙

1. 프론트매터의 `title`, `date`, `summary`는 필수다. 하나라도 빠지면 빌드가 실패한다.
2. `tags`는 기본값 빈 배열, `draft`와 `keyPoint`는 기본값 `false`다. 적지 않아도 검증을 통과한다.
3. 초안 글은 `import.meta.env.PROD`가 참일 때 목록과 정적 경로에서 모두 빠진다. 개발 서버에서는 그대로 보인다.
4. 노출 대상 글은 언제나 발행일 내림차순이다. 뒤따르는 선별 함수는 이 순서를 그대로 물려받는다.
5. 홈 최신 글은 최대 5편이다(`RECENT_POST_LIMIT`).
6. 지식 맵은 `keyPoint`를 표시한 글을 발행일 내림차순으로 최대 5편 고른다(`MAP_NODE_LIMIT`). 표시한 글이 하나도 없을 때만 최신 글로 채우고, 하나라도 있으면 모자라도 최신 글로 채우지 않는다. 앞세울 글을 고르는 일이 작성자의 판단이기 때문이다.
7. 읽기 시간은 코드 블록, 인라인 코드, 링크와 이미지 문법, 마크다운 기호와 공백을 뺀 글자 수를 500으로 나눠 올림한 값이며 항상 1 이상이다.
8. 글 주소는 `/posts/` 뒤에 `post.id`를 그대로 붙인다. `post.id`가 `src/content/posts` 기준 상대 경로이므로 발행일을 접두사로 덧붙이지 않는다.
9. `related`가 가리키는 글이 컬렉션에 없으면 예외를 던져 빌드를 멈춘다. 존재하지만 노출 대상이 아니면 `undefined`를 돌려주고 화면에서 영역 자체가 사라진다.
10. 검색 대상 문자열은 제목, 요약, 태그를 공백으로 이어 소문자로 낮춘 값이다. 본문은 색인하지 않는다.

### 예외 케이스

| 상황 | 처리 |
| --- | --- |
| `keyPoint`를 표시한 글이 없다 | 최신 글 5편으로 지식 맵을 채운다 |
| `keyPoint`를 표시한 글이 5편을 넘는다 | 발행일이 늦은 5편만 남긴다 |
| 글이 5편보다 적다 | 있는 만큼만 돌려준다. 격자의 빈 칸은 화면 쪽이 채운다 |
| 본문이 비어 있다 | 읽기 시간이 1분이다 |
| `category`가 없다 | 읽기 시간만 남기고 구분용 가운뎃점도 넣지 않는다 |
| `related`를 적지 않았다 | `undefined`를 돌려준다 |
| `related`가 초안을 가리킨다 | 운영 빌드에서 `undefined`가 되어 영역이 사라진다 |
| `related`가 없는 글을 가리킨다 | `Error`를 던져 빌드를 멈춘다 |
| `.obsidian` 아래 마크다운이 있다 | 로더의 `pattern`이 제외하므로 글로 잡히지 않는다 |
