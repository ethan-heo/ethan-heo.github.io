# 디자인 시스템(DESIGN) — 도메인 개요

계획서 출처: `docs/plans/2026-08-28-design-system/theme/`, `docs/plans/2026-08-28-design-system/ui/`, `docs/plans/2026-08-28-home-screen/base/token.md`, `docs/plans/2026-08-28-tag-style/tag/`

## 도메인 정의

디자인 시스템 도메인은 화면이 참조할 시각 언어를 정의한다. 색·서체·간격·크기 토큰과 두 테마의 전환, 그리고 어느 화면에서나 재사용하는 공용 컴포넌트가 여기에 속한다.

각 화면이 이 토큰과 컴포넌트를 어떻게 조합하는지는 [`홈_화면(HOME)`](../홈_화면(HOME)/01_도메인_개요.md)과 [`글_목록과_상세(POST)`](../글_목록과_상세(POST)/01_도메인_개요.md)가 맡는다. 본문 조판은 마크다운 변환에 딸린 규칙이므로 [`본문_렌더링(RENDER)`](../본문_렌더링(RENDER)/01_도메인_개요.md)에 둔다.

### 책임 범위

| 구분 | 내용 |
| --- | --- |
| 담당한다 | `@theme` 토큰 정의, 다크 토큰 재정의, 테마 초기화와 전환, 전역 기본 스타일, 페이지 골격(`BaseLayout`), 공용 컴포넌트(`SiteHeader`, `SiteBrand`, `SiteFooter`, `ThemeToggle`, `SectionHead`, `PageIntro`, `Tag`, `TagList`, `EmptyState`) |
| 담당하지 않는다 | 화면별 배치와 문구(HOME, POST), 본문 조판(RENDER), 글 자료(CONTENT) |

## 유비쿼터스 용어 사전

| 용어 | 영문 표기 | 정의 |
| --- | --- | --- |
| 토큰 | `@theme` 변수 | 색·서체·간격·크기의 단일 출처. Tailwind 유틸리티로도 쓰인다 |
| 테마 | `data-theme` | 라이트와 다크 두 값. 루트 요소의 데이터 속성으로 나타낸다 |
| 테마 초기화 스크립트 | inline script | 첫 렌더링 전에 테마를 정해 잘못된 테마가 잠깐 보이는 것을 막는 스크립트 |
| 강조색 | `--color-accent` | 링크와 눈길을 끄는 자리에 쓰는 색 |
| 보조 배경 | `--color-soft` | 지식 맵의 중심 글과 노드 호버 배경에만 쓰는 색 |
| 태그 배경 | `--color-tag-bg` | 태그 컴포넌트 배경에만 쓰는 색 |
| 넓은 화면 | `wide` | 701px 이상. 지식 맵과 글 목록이 재배치되는 경계 |
| 조작 식별자 | `data-od-id` | 스크립트와 검증이 요소를 찾는 데 쓰는 표식 |
| 페이지 골격 | `BaseLayout` | `<head>`와 헤더·본문·푸터의 세로 배치를 담는 레이아웃 |

## 핵심 비즈니스 규칙

1. 색과 크기 값은 `global.css`의 `@theme static` 한 곳에만 적는다. 컴포넌트는 토큰을 참조하고 값을 다시 적지 않는다.
2. 다크 테마는 색상 토큰 재정의로 처리한다. 토큰 하나로 표현되지 않는 속성에만 `dark:` 변형을 쓴다.
3. 테마는 저장 값이 있으면 그 값을, 없으면 `prefers-color-scheme`을 따른다. 판정은 `<head>`의 인라인 스크립트가 첫 렌더링 전에 끝낸다.
4. 테마를 바꾸면 `localStorage`의 `theme` 키에 남긴다. 저장이 막혀 있어도 그 세션 안에서는 전환이 유지된다.
5. 테마 토글 버튼의 접근 가능한 이름은 현재 상태가 아니라 누르면 일어날 동작을 설명한다.
6. 아이콘 조작의 터치 영역은 최소 높이 44px을 지킨다.
7. 본문 폭은 680px, 페이지 최대 폭은 70rem이다. 좌우 여백은 40px이고 430px 이하에서 32px로 줄인다.
8. 서체는 Noto Sans KR 한 갈래로 통일한다. 세리프 토큰은 두지 않는다.
9. 폰트 요청이 실패해도 대체 서체로 그려지고 배치가 흐트러지지 않아야 한다.
10. 포커스 표시는 `--focus-ring`을 쓰는 2px 윤곽선이며 어느 조작에서도 지우지 않는다.
11. 축소 모션을 선호하는 환경에서는 전환과 애니메이션을 사실상 없앤다.
12. 태그는 링크가 아니다. 모서리 4px, 테두리 없음, `--color-tag-bg` 배경을 쓴다.
13. `DESIGN.md`에 적힌 토큰 값은 `global.css`의 값과 문자열까지 같아야 한다.

### 예외 케이스

| 상황 | 처리 |
| --- | --- |
| `localStorage`에 접근할 수 없다 | `try`/`catch`로 감싸 실패를 삼키고 시스템 설정을 따른다 |
| 저장 값이 `light`도 `dark`도 아니다 | 저장 값을 무시하고 `prefers-color-scheme`을 따른다 |
| 스크립트가 실행되지 않는다 | 테마 전환만 동작하지 않고 라이트 테마 화면은 그대로 읽을 수 있다 |
| 구글 폰트를 받지 못한다 | `ui-sans-serif` 이하의 대체 서체로 그린다 |
| 토큰을 참조하는 자리가 없다 | `@theme static`이라 사용 여부와 무관하게 모두 방출한다 |
| `SectionHead`에 보조 텍스트가 없다 | 제목 줄이 무너지지 않고 개수 표시만 빠진다 |
| `EmptyState`에 링크를 넘기지 않는다 | 안내 문구만 그린다 |
