# 디자인 시스템(DESIGN) — 도메인 특화 가이드

## 외부 의존성

| 대상 | 종류 | 용도 |
| --- | --- | --- |
| `tailwindcss` | 라이브러리 | 유틸리티 클래스와 `@theme` 토큰 체계 |
| `@tailwindcss/vite` | 빌드 플러그인 | Vite에 Tailwind를 붙인다 |
| Google Fonts | 서드파티 서비스 | Noto Sans KR 400·500·700 |
| `localStorage` | 브라우저 API | 테마 선택 보관 |
| `matchMedia` | 브라우저 API | `prefers-color-scheme` 판정 |

### 설정

| 항목 | 값의 출처 | 비고 |
| --- | --- | --- |
| `@custom-variant dark` | `src/styles/global.css` | `[data-theme="dark"] &` |
| `@theme static` | 같은 파일 | 토큰의 단일 출처 |
| 폰트 링크 | `src/layouts/BaseLayout.astro` | `preconnect` 두 줄과 스타일시트 한 줄 |
| 테마 초기화 | 같은 파일의 `is:inline` 스크립트 | `<head>`에 두어 첫 페인트 전에 실행한다 |
| Tailwind 플러그인 | `astro.config.mjs`의 `vite.plugins` | `tailwindcss()` |
| 디자인 원본 | `DESIGN.md` | 토큰 값과 컴포넌트 초안. `global.css`와 값이 일치해야 한다 |

## 핵심 테스트 시나리오

| ID | 상황 | 기대 동작 |
| --- | --- | --- |
| T1 | `astro build`를 돌린다 | 오류 없이 끝나고 결과 CSS에 유틸리티 클래스가 들어 있다 |
| T2 | `DESIGN.md`의 토큰과 `global.css`를 대조한다 | 값이 문자열까지 같다 |
| T3 | 두 테마에서 본문과 배경의 대비를 잰다 | WCAG AA를 만족한다 |
| T4 | 저장 값 없이 시스템을 다크로 두고 연다 | 다크로 그려지고 첫 페인트에 라이트가 스치지 않는다 |
| T5 | 라이트로 바꾸고 새로 고친다 | 저장 값이 시스템 설정을 이긴다 |
| T6 | 토글을 누른다 | `localStorage.theme`에 값이 남고 접근 가능한 이름이 다음 동작을 설명한다 |
| T7 | 아이콘 조작의 크기를 잰다 | 계산된 높이가 44px 이상이고 폭이 36px 이상이다 |
| T8 | 폰트 요청을 막고 연다 | 대체 서체로 그려지고 배치가 흐트러지지 않는다 |
| T9 | `--font-serif` 참조를 검색한다 | 코드 어디에도 남아 있지 않다 |
| T10 | `--color-soft`와 `--color-tag-bg`를 두 테마에서 계산한다 | 각각 서로 다른 값으로 나온다 |
| T11 | 태그 요소의 계산값을 본다 | `border-radius` 4px, `border-width` 0, 배경이 투명하지 않다 |
| T12 | 태그 목록의 간격을 잰다 | `column-gap` 6px, `row-gap` 2px |
| T13 | 키보드로 조작을 순회한다 | `:focus-visible` 윤곽선이 `--focus-ring`으로 보인다 |
| T14 | 축소 모션을 켠다 | 전환과 애니메이션 시간이 사실상 0이 된다 |
| T15 | 1440px과 430px 이하에서 본다 | 최대 폭이 1120px이고 좁은 화면에서 좌우 여백이 줄어든다 |
| T16 | 두 페이지의 `h1` 개수를 센다 | 각각 하나이고 `BaseLayout`에 인라인 스타일이 없다 |

### 실행 방법

```bash
npm run build
npm run dev
```

시각 검증은 개발 서버 화면과 브라우저 개발자 도구의 계산값으로 확인한다.

## 트러블슈팅

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 첫 화면에 잘못된 테마가 잠깐 보인다 | 초기화 스크립트가 `<head>`에서 벗어났거나 `is:inline`이 빠졌다 | `BaseLayout`의 `<head>` 안에 인라인 스크립트로 두었는지 확인한다 |
| 테마를 바꿔도 다음 방문에 되돌아간다 | `localStorage` 쓰기가 막혔다 | 브라우저의 사이트 데이터 차단 설정을 확인한다. 코드는 이 상황을 오류로 다루지 않는다 |
| 새 토큰을 넣었는데 CSS에 없다 | `@theme` 밖에 적었다 | `@theme static` 블록 안으로 옮긴다 |
| 다크에서 특정 요소만 색이 남는다 | 토큰이 아니라 값을 직접 적었다 | 해당 자리를 토큰 참조로 바꾼다 |
| 유틸리티 클래스가 적용되지 않는다 | `@tailwindcss/vite` 플러그인이 빠졌다 | `astro.config.mjs`의 `vite.plugins`를 확인한다 |
| 한글이 대체 서체로 그려진다 | 폰트 요청이 막혔거나 `preconnect`가 빠졌다 | 네트워크 탭에서 요청 결과를 확인한다. 배치가 흐트러지지 않으면 정상 동작이다 |
| 태그를 눌렀는데 반응이 없다 | 태그는 링크가 아니다 | 의도된 동작이다. 목록을 좁히려면 모든 글 화면의 검색을 쓴다 |
| 헤더 아이콘이 눌리지 않는다 | 터치 영역이 작다 | `min-h-11 min-w-9` 클래스가 남아 있는지 확인한다 |
